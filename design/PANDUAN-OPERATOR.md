# Panduan Operator Backdrop · International Class 2026

## Urutan pemutaran
1. **Video utama** (`IC2026_Video_Utama_*.mp4`, 5:10). Diputar sekali sebagai pembuka talkshow.
   Frame terakhir berisi "Please welcome our moderator, Raisa Alatas". Biarkan frame itu diam di layar saat Raisa masuk.
   Jangan aktifkan loop untuk video ini.
2. **Video dokumenter** (`IC2026_Dokumenter_Loop_110s.mp4`, 1:50, tanpa suara). Diputar terus selama sesi talkshow dengan mode loop.

## Cara menyalakan loop untuk dokumenter
- **VLC:** buka video, klik tombol loop (ikon panah melingkar) sampai bertuliskan "Loop one", atau tekan `L`. Masuk layar penuh dengan `F`.
- **PowerPoint:** Insert, Video, This Device. Pilih videonya, buka tab Playback, centang "Loop until Stopped" dan "Play Full Screen", lalu atur Start menjadi "Automatically".
- **Windows Media Player / Media Player:** tekan `Ctrl + T` untuk repeat.
